---
title: What is BugsPort
description: Integrate BugsPort, send your first issue, and diagnose mobile failures.
---

BugsPort helps mobile teams catch crashes, ANRs, and network failures, then inspect the issue with the context needed to fix it.

Use these docs to:

- Initialize an [Android](/sdks/android/getting-started) or [iOS](/sdks/ios/getting-started) SDK, or send a first issue through the [REST API](/api).
- Review [crashes](/product/crashes), [ANRs](/product/anrs), [network traces](/product/network-traces), and [issue triage](/product/issue-triage) in the product.
- Manage [organizations, teams, and projects](/manage/organizations-teams-projects).

Project ingestion authenticates with a project-scoped `x-api-key`. It does not use a signed-in user session.
