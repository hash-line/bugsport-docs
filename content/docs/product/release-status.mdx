## Current status

- **Android:** pre-alpha. The released package is documented at [Android](/sdks/android/getting-started). Initialize with `io.bugsport` types, both `BugsPort.initialize` overloads, and nested `apiHalt`; use REST for the first-issue verification path.
- **iOS:** pre-alpha. The released binary package is documented at [iOS](/sdks/ios/getting-started). The KMP public contract is `BugsPort.companion.initialize(config:)`; the published XCFramework may still lag that export.
- **Flutter:** coming soon. No dependency, version, or initialization API is published.
- **React:** coming soon. No dependency, version, or initialization API is published.
- **REST API:** available through the reviewed OpenAPI snapshot and the [REST API guide](/api).
- **npm package:** none is published or documented.
