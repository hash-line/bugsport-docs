## Hierarchy

BugsPort organizes work as **organizations → teams → projects**. The current **Projects** screen creates a project by selecting an organization and then a team; the UI describes projects as holding bug reports inside a team.

## Create or select a project

1. Create or select an organization.
2. Create or select a team in that organization.
3. Open **Projects** and choose the organization and team.
4. Create or select the project where you will inspect issues.

Project-scoped REST paths and project API keys use the selected project ID. The [REST API guide](/platforms/rest-api) shows the verified authentication model.
