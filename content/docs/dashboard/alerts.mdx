## Project alerts

The current project settings route includes an **Alerts** tab. It offers a project-level **Receive alerts for this project** switch and per-kind delivery toggles for the channels present in the UI: email and in-app.

## Configure alerts

1. Open the project’s **Settings** route.
2. Select **Alerts**.
3. Turn on **Receive alerts for this project**.
4. Set the available email and in-app choices for each alert kind.

This page documents only the current settings UI. It does not promise external alert channels, custom rules, or provider availability.
