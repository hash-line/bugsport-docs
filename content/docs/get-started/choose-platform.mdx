## Outcome

You will choose a verified integration path for your application.

## Prerequisites

Have the project ID and project API key from project settings. The mobile clients use that project-scoped key as `x-api-key` for ingestion.

## Configuration

- [Android](/platforms/android) is a pre-alpha Maven Central package for Android API 24 and later. Initialize with `BugsPort.initialize` and nested `apiHalt`.
- [iOS](/platforms/ios) is a pre-alpha Swift Package Manager binary package for iOS 14 and later. Initialize with `BugsPort.companion.initialize(config:)`.
- [REST API](/platforms/rest-api) is the source-backed fallback for a deterministic first issue.
- [Flutter](/platforms/flutter) is coming soon and has no released package.

## Send an issue

For the most direct verification route, use the [REST API guide](/platforms/rest-api) with `validateOnly=true`.

## Verify in BugsPort

Confirm the validation request succeeds, then submit a real issue only when the request payload is ready.

## Troubleshooting

See [troubleshooting](/reference/troubleshooting) for credentials and request failures.
