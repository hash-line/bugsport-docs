---
title: Verify the integration
description: Check credentials and payload validation before creating a real issue.
---

## Outcome

You will know that BugsPort can authenticate your project and validate its first issue payload.

## Prerequisites

Use the project ID and project API key from project settings. For mobile ingestion, the key is the project-scoped `x-api-key` credential.

## Configuration

Open the verified [Android](/platforms/android), [iOS](/platforms/ios), or [REST API](/platforms/rest-api) path for your application.

## Send an issue

Use the REST path with `validateOnly=true` before sending a real issue. This verifies a non-empty JSON Patch body without creating an issue.

## Verify in BugsPort

Treat the validation response as the first integration checkpoint. Then send the same supported payload without `validateOnly=true` and confirm the created issue in your project.

## Troubleshooting

See [troubleshooting](/reference/troubleshooting) for API-key, project-ID, or payload failures.
