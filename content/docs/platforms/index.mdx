## Outcome

You will select a supported BugsPort platform guide and a safe path to a first issue.

## Prerequisites

Get the project ID and project API key from project settings. Mobile ingestion authenticates with the project-scoped `x-api-key` header.

## Configuration

- [Android](/docs/platforms/android) — pre-alpha, Maven Central 0.1.6.
- [iOS](/docs/platforms/ios) — pre-alpha, Swift Package Manager release `v0.1.1-alpha-test`.
- [REST API](/docs/platforms/rest-api) — available for project-scoped issue ingestion.
- [Flutter](/docs/platforms/flutter) — Coming soon.

## Send an issue

Use the [REST API](/docs/platforms/rest-api) validation request when you need a source-backed first issue path.

## Verify in BugsPort

Validate the request before creating a real issue, then confirm it in the selected project.

## Troubleshooting

See [troubleshooting](/docs/reference/troubleshooting) for setup failures.
