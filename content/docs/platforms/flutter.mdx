## Outcome

Flutter support is **Coming soon**. There is no released BugsPort Flutter package to configure today.

## Prerequisites

If you need to ingest issues now, obtain the project ID and project API key from project settings for the [REST API fallback](/docs/platforms/rest-api).

## Configuration

No Flutter dependency, version, or initialization API is published. Watch the [platform overview](/docs/platforms) for release status.

## Send an issue

Use the [REST API fallback](/docs/platforms/rest-api) with a project-scoped `x-api-key` and `validateOnly=true`.

## Verify in BugsPort

Validate the REST payload before creating a real issue, then confirm it in the selected BugsPort project.

## Troubleshooting

For a current integration path, see the [REST API guide](/docs/platforms/rest-api) or [troubleshooting](/docs/reference/troubleshooting).
