## Outcome

You will initialize the current pre-alpha Android SDK with a BugsPort project ID and API key.

## Prerequisites

The current `co.hashline:bugsport-android` release is `0.1.6`. Its source sets `minSdk` to 24 and targets JVM 21 with Java source and target compatibility 21, so use Android API 24+ and JDK 21. Get the project ID and project API key from project settings; the SDK uses the key for project-scoped `x-api-key` ingestion.

This package is pre-alpha. Review the [0.1.6 pre-alpha release](https://github.com/hash-line/bugsport-client/releases/tag/v0.1.6-pre-alpha) before adopting it.

## Configuration

Add the released Maven Central artifact:

```kotlin
dependencies {
    implementation("co.hashline:bugsport-android:0.1.6")
}
```

Initialize it from your `Application` class. The context overload is provided by the Android platform initializer, so import it with the SDK types:

```kotlin
import com.hashline.bugsport.BugsPort
import com.hashline.bugsport.BugsPortConfig
import com.hashline.bugsport.shared.initialize

val config = BugsPortConfig.Builder()
    .apiKey("YOUR_PROJECT_API_KEY")
    .projectId("YOUR_PROJECT_ID")
    .build()

BugsPort.initialize(this, config)
```

## Send an issue

The current public Android source does not expose a completed app-facing first-issue call. Use the [REST API validation request](/platforms/rest-api) to validate a first issue for this project.

## Verify in BugsPort

Run the REST request with `validateOnly=true`. After it validates, remove that query parameter to create the issue and confirm it in BugsPort.

## Troubleshooting

Check the project ID, `x-api-key`, API 24 minimum, and JDK 21 requirement. For further help, see [troubleshooting](/reference/troubleshooting).
