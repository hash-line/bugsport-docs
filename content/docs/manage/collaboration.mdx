## Comments

Issue detail loads comments for the selected issue. The current comment composer supports a comment body, project-member `@` mention suggestions, replies, and supported comment attachments. Use the issue detail after assigning or filtering work to keep the discussion with the issue.

## Attachment limits in the current composer

The web composer accepts JPEG, PNG, GIF, WebP, SVG, PDF, plain-text, and ZIP files, with a 5 MB maximum per selected file. These are current UI validations, not a general REST upload policy; use the [attachment endpoint reference](/api/reference/v1/projects/projectid/attachments/post) for the API contract.

## Workflow

1. Open an issue from **Issues**.
2. Add a comment, using `@` to select a project member when needed.
3. Attach only files accepted by the current composer when commenting in the web UI.
4. Review the issue activity and replies in the same detail view.
